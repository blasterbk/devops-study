# 🤖 Module 10 — AI/ML Workloads, GPUs & Cloud-Native Innovations

> **Deep Learning Guide (University-Level + Interview-Oriented)**

Welcome to **Module 10: AI/ML Workloads, GPUs & Cloud-Native Innovations**. This module provides a complete, university-level, and production-oriented deep dive into NVIDIA GPU Operator architecture, Multi-Instance GPU (MIG) hardware slicing, Kubernetes 1.30+ Dynamic Resource Allocation (DRA) API (`ResourceClaim`/`ResourceClass`), KubeRay Operator for distributed Ray compute clusters, Kueue batch queuing and multi-tenant GPU borrowing, LLM inference model serving (vLLM PagedAttention KV-cache, Triton, KServe), Vector Database architecture (Milvus, Qdrant, pgvector), WebAssembly (`runwasi` containerd shim), Confidential Containers (CoCo hardware TEE memory encryption), Spot GPU cost optimization with PyTorch checkpointing, and AI/ML infrastructure troubleshooting labs.
